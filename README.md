# dariogoldbach.nl

De website van Dario Goldbach, schrijver, columnist en organisator.

- `site/` bevat de website zoals die online komt (HTML, CSS en JavaScript, zonder bouwstap).
- `build.py` maakt de pagina's in `site/` opnieuw aan. De teksten staan in dat script. Draai `python3 build.py` na een wijziging.
- Netlify publiceert de map `site/` (zie `netlify.toml`).
